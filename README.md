# 📌 게임 소개
엔진 : UnrealEngine 5.5

에디터 : Visual Studio 2022

제작 기간 : 약 10개월

개발 규모 : 1인 개발

언리얼 엔진으로 구현한 소울류 장르의 게임 프로젝트입니다.

# 🛠 주요 기능
### ⚔️ 캐릭터 시스템
* 스태미나 연동 구르기 및 무적 프레임 (i-frame) 구현
* 입력 버퍼 기반 공격 콤보 시스템
* 가드 시 스태미나 감소 및 고갈 시 그로기 상태 돌입
* 그로기 상태의 적에게 근접 시 플레이어 전용 치명타 (백스탭 포함)
* 멀티 타겟 락온 시스템 구현 (좌우 전환 지원)
* 시간 경과에 따른 스태미나 자동 회복

### 👾 적 시스템
* 웨이포인트 기반 AI 순찰
* 시야각 / 거리 기반 플레이어 탐지
* 랜덤 공격 시퀀스 기반 전투 AI
* 사망 애니메이션 처리
* 사망 시 소울 / 아이템 드롭

### 🛡️ 체간 시스템
* 적 전용 체간 수치 관리
* 퍼펙트 가드 성공 시 적 체간 감소, 실패 시 플레이어 스태미나 감소
* 체간 고갈 시 그로기 상태 돌입 및 치명타 대기 상태 전환
* 시간 경과에 따른 체간 자동 회복

### 💀 소울 시스템
* 적 처치 시 소울 획득
* 사망 시 소울 드롭
* 드롭 위치로 이동하여 소울 회수
* 회수 전 다시 사망 시 소울 소멸
* 소울을 화폐로 상점에서 아이템 구매

### 🎒 인벤토리 / 장비 시스템
* 아이템 카테고리 분류 (방어구, 무기, 소모품, 중요 아이템, 강화 재료)
* 아이템 획득 및 관리 (사용, 내려놓기, 폐기)
* 아이템 상세 정보 표시
* 장비 장착 및 해제
* 장비 장착 시 현재 장비와 스탯 비교
* 소비 아이템 퀵슬롯 등록 및 사용

### 🔥 화톳불 시스템
* 휴식을 통한 HP / 스태미나 회복
* 휴식 시 처치한 적 리스폰 및 리셋
* 레벨 업을 통한 스탯 포인트 분배
  - Strength (공격력과 방어력) / Endurance (스태미나) / Vigor (체력)
 
### 💾 세이브 / 로드 시스템
* New Game 시 캐릭터 이름 입력 후 세이브 파일 생성과 게임 시작
* Load Game 시 세이브 파일 목록 표시 및 선택 로드
* Continue 시 마지막 플레이 세이브 데이터 자동 로드
* 저장 데이터 항목
  - 캐릭터 이름 / 위치 / HP / 스탯
  - 보유 소울 및 바닥에 드롭된 소울 위치와 소울량
  - 인벤토리 아이템 및 장착 중인 아이템
  - 처치한 적 상태
  - 레벨 내 배치 아이템 획득 여부 (레벨 에디터에서 직접 기입하는 UniqueID 기반)
  - 적 드롭 아이템 획득 여부 (FGUID 기반 DropID)

### 🖥️ UI 시스템

#### HUD
* HP / 스태미나 표시
* 소모품 퀵슬롯 표시
* 보유 소울 및 드롭 소울 수량 표시
* 아이템 획득 팝업 표시

#### 타이틀 화면
* 세이브 파일 유무에 따른 버튼 동적 표시
  - 세이브 파일 없음 : New Game
  - 세이브 파일 있음 : New Game / Continue / Load Game
* New Game 시 캐릭터 이름 입력 프롬프트 표시
* Load Game 시 세이브 파일 목록 표시
